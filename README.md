# Proyecto de GitHub Actions

Este es un projecto/curso donde se manejo el GitHub Actions para modificar el README y el package.json
Esto con el fin de modificar el versionamieto y mostrarlo en dichos documentos cada vez que se haga un commit que empiece con:

* Major: Incrementa al version
* Feature: Incremente el minor de la version
